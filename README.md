# Human Activity Detection

Classifies human activity such as standing and walking based on 3-axis accelerometer and 3-axis gyroscope attached on left hand wrist.

### Dataset Source
```
https://www.kaggle.com/datasets/zoya77/agro-human-activity-imu-sensor-dataset?select=HAR-for-human-robot-interaction-in-agriculture
```
